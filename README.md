# DeskFit-Occupational-Wellness
A Research-based Android application for mitigating sedentary work risks through job-specific ergonomics and gamification

📌 Project Overview
DeskFit is an Android application designed to mitigate sedentary work risks through professional-specific stretches and gamified cognitive breaks.

🚀 Key Features
Job-Specific Profiling: Custom exercise sets for Office Workers and Drivers.
Gamified Ecosystem: 8 cognitive mini-games to refresh mental load.
Real-time Global Leaderboard: Powered by Firebase to foster healthy competition.

📲 How to Run
Download the DeskFit_v1.0.apk from the /Release folder.
Enable "Install from Unknown Sources" on your Android device.
Launch and start your wellness journey!

🛠 Tech Stack
Language: Java (Android SDK)
UI/UX: Material Design 3, ConstraintLayout for varied aspect ratios.
Database: Firebase Realtime Database (NoSQL).
Auth: Firebase Authentication (OAuth 2.0).
